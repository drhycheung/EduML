EduML — Learning Analytics Demo

Enter a student’s engagement indicators, absence band and semester to obtain a predicted performance level and a three-band performance class (Low / Medium / High), using gradient-boosted trees.

Sample size. The source dataset contains student records from the Kalboard 360 learning management system. records were used for modelling. All performance figures on this page are out-of-fold cross-validated: the data were divided into folds, and each figure was calculated on the records held out by a fold, using a model fitted on the remaining records. No record is therefore used to score a model that was fitted on it. Each reported figure is shown beside the simplest possible baseline for comparison.
